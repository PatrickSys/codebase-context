# Test Session Template

Copy this folder for new test sessions → `SSP_Portal_[MMDD]`

## Files
| File | Purpose |
|------|---------|
| `TEST_SESSION.md` | Main document - copy to new session folder |
| `AGENTS.minimal.md` | 8-line minimal AGENTS.md for `-Min` runs |

## Quick Start
1. Copy folder → `SSP_Portal_XXXX`
2. Update: Date, MCP Version, Focus, Agent, Model
3. Run compulsory configs first: `-MCP/Min` × 3, `+MCP/Min` × 3
4. Fill in results, have evaluator agent review
